## CLI Coding Supervisor

Let Grok Bot supervise your background coding CLI through your own MCP bridge: start a task in an enrolled Git repository, inspect responses, answer scoped technical questions, request improvements in the same session, and finish only after current verification passes.

Works with compatible ACP v1 stdio agents and supported native adapters. Live checks have exercised Codex, Antigravity, OpenCode and Cline; authentication, model access and vendor-specific features still require individual validation. Grok Build inference was balance-blocked. Claude account testing was excluded. A new CLI advertising ACP is not automatically certified.

**Two parts required:** add this Bot template, then install the separate coding-agent bridge runtime on your coding computer. You supply the repository, native CLI login, exact model, immutable verifier and HTTPS/OAuth connection. No xAI API key is required for the Grok Bot caller route. The template does not include a hosted bridge, provider subscriptions, credentials or the creator's computer.

**Boundaries:** native approvals and administrator rules remain in force; human-only authentication/security steps require you. Quota errors stop work. No account rotation, silent model substitution, uncertain mutation replay, automatic purchases, merging or pushing. The bridge uses isolated Git worktrees but is not an operating-system sandbox. Your host must remain online; fully unattended operation and physical reboot acceptance are not certified.

**Privacy:** tasks and selected repository context are processed by Grok Bot, the selected coding provider and your chosen tunnel. Protect those services accordingly. Each recipient connects their own private installation; never embed a personal endpoint or credential in a public template.

**Getting started:** install the CLI archive, follow the included standalone guide, approve OAuth locally, discover providers, and run the included acceptance prompts. This is an unofficial community integration, not an xAI or provider marketplace endorsement. Public template/release links must be supplied by the publisher after native publication; none is included here.
